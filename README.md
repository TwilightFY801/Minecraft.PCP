# Minecraft.PCP

面向 **Minecraft 1.21.1 / NeoForge** 的趣味工具模组（内部工程名 `dangtools`），最初为整合包 **《你好,北极星》** 开发。

模组 id 为 `dangtools`，游戏内显示名为 **Minecraft.PCP**。所有物品/方块都在创造模式物品栏的 **「党」** 标签页下。

---

## 平台与前置

| 项 | 值 |
| --- | --- |
| Minecraft | 1.21.1 |
| 模组加载器 | NeoForge 21.1.243（Java 21） |
| 前置（可选） | **机械动力 Create**、**航空学 Aeronautics**（含底层物理库 Sable） |

> 前置为**可选**：锤子、镰刀、组合工具、飞行执照、国旗**不装 Create 也能用**；
> **党的动力**与**党的分量**需要 Create / 航空学才能发挥完整效果。

---

## 物品（作用）

| 物品 | 作用 |
| --- | --- |
| **锤子** `hammer` | 挖掘速度更快；对着矿石右键，可直接产出掉落物（无需挖掉方块），且**掉落物翻倍**。 |
| **镰刀** `sickle` | 收割农作物时**掉落物翻倍**。 |
| **来自中国伟大的党** `party_sickle_hammer` | 锤子与镰刀的结合体：**攻击力大幅加强**，并同时继承两者的能力（**掉落物翻倍**、**挖掘速度更快**）。 |
| **飞行执照** `flight_license` | 放在**副手**时相当于**无限不死图腾**；穿在**胸甲**时获得保护等增益、可当**鞘翅**滑翔，且**外观完全隐形**（自己和他人都看不到）。 |

## 方块（作用）

| 方块 | 作用 |
| --- | --- |
| **党的动力** `party_power` | 与原版**创造马达一致**（转速可调、无需消耗即可供能），但**应力数值大幅提高**；并且可以**在生存模式下合成**。 |
| **党的分量** `party_weight` | 目前**机械动力中唯一可以调节"重量/质量"的方块**（0 ~ 1000，1000 = 基岩的重量）。对物理化的航空学生效——可能是未来众多玩家很需要的东西。 |
| **国旗** `flag` | 在范围内提供**满级信标增益**，可放置在**任意位置**。 |

> 提示：物品可用 `/give @p dangtools:<id>` 获取（id 见上表英文名）。

## 下载

交付文件夹 **`交付/`** 内直接下载：

```
交付/Minecraft.PCP-2.0.0.jar
```

把该 jar 放进整合包/存档的 `mods` 目录即可。

## 构建

需要 JDK 21 与 Gradle（仓库自带 wrapper）。

1. 把第三方**编译期依赖 jar** 放入 `libs/`（本仓库不分发，说明见 `libs/README.md`）。
2. 构建：

```bash
./gradlew build
```

产物在 `build/libs/` 下。
